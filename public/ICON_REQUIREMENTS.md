# Icon Requirements

Place the following icon files in this `public` folder:

## Favicon Files (Browser Tab Icons)
- **favicon.ico** - Classic favicon (16x16 or 32x32, ICO format)
- **icon-16x16.png** - 16x16 pixels (PNG)
- **icon-32x32.png** - 32x32 pixels (PNG)
- **icon-192x192.png** - 192x192 pixels (PNG, for Android)
- **icon-512x512.png** - 512x512 pixels (PNG, for Android)

## Apple Touch Icon
- **apple-touch-icon.png** - 180x180 pixels (PNG, for iOS devices)

## Open Graph Image (Discord/Social Media Preview)
- **og-image.png** - 1200x630 pixels (PNG or JPG)
  - This is the image that shows when you share the website on Discord, Facebook, Twitter, etc.
  - Recommended: Use a high-quality image with your logo/branding

## Quick Summary
- **Minimum required**: favicon.ico (32x32) and og-image.png (1200x630)
- **Recommended**: All sizes for best compatibility across devices and platforms
